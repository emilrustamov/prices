# Инструкция по настройке

## 1. Настройка базы данных

Отредактируйте файл `config.php` и укажите правильные данные для подключения к MySQL:
- `DB_HOST` - хост БД (обычно `localhost`)
- `DB_USER` - пользователь БД
- `DB_PASS` - пароль БД

## 2. Создание базы данных и таблиц

Выполните в терминале:
```bash
mysql -u root -p < database.sql
```
Или если база уже создана:
```bash
mysql -u root -p bitrix24_reports < database.sql
```

## 3. Первая синхронизация данных

Запустите синхронизацию:
```bash
cd /var/www/prices
php sync.php
```

Это загрузит:
- Все контракты из Bitrix24
- Названия юнитов
- Рассчитает месячные отчеты

## 4. Настройка автоматической синхронизации (cron)

Добавьте в crontab для регулярной синхронизации (например, каждый час):
```bash
crontab -e
```

Добавьте строку:
```
0 * * * * cd /var/www/prices && /usr/bin/php sync.php >> /var/www/prices/logs/sync.log 2>&1
```

## 5. Просмотр отчета

Откройте в браузере:
```
https://prices.colifeb24apps.ru/
```

Отчет будет загружаться из базы данных, что значительно быстрее, чем загрузка напрямую из Bitrix24.

## Структура проекта

- `index.php` - отображение отчета (читает из БД)
- `sync.php` - синхронизация данных из Bitrix24 в БД
- `config.php` - настройки подключения к БД
- `database.sql` - структура базы данных
- `crest.php`, `crestcurrent.php` - SDK для работы с Bitrix24 API
